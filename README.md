# Pendurai

Pendurai é um sistema de gestão de compras e vendas, com foco em pequenos negócios que utilizam o famoso "fiado". O nome do projeto faz uma analogia ao ato de "pendurar a conta", trazendo uma solução moderna e prática para gerenciar vendas a prazo e outras operações comerciais.

## Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- **[Bun](https://bun.sh/):** Um runtime ultrarrápido para JavaScript e TypeScript, utilizado para gerenciar dependências e scripts do projeto.
- **[Vite](https://vitejs.dev/):** Um build tool moderno e rápido, ideal para projetos React.
- **[React](https://reactjs.org/):** Biblioteca JavaScript para construção de interfaces de usuário.

## Funcionalidades

- Cadastro de produtos e clientes.
- Registro de vendas, incluindo a opção de "pendurar" contas.
- Controle de pagamentos e saldos pendentes.
- Interface amigável e responsiva para facilitar o uso em dispositivos móveis.

## Scripts Disponíveis

No projeto, você pode executar os seguintes scripts:

- `bun dev`: Inicia o servidor de desenvolvimento utilizando o Vite.
- `bun build`: Realiza o build de produção do projeto.
- `bun preview`: Visualiza o build de produção localmente.
- `bun lint`: Analisa o código em busca de problemas utilizando o Biome.
- `bun format`: Formata o código automaticamente utilizando o Biome.

## Como Executar o Projeto

Basta rodar o projeto utilizando `bun run dev`
